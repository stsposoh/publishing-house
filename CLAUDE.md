# Презентационные лендинги

Цель папки — лендинги-витрины, которые выглядят так, будто их сделал сильный дизайнер-человек, а не ИИ.
Каждый лендинг должен иметь свой характер. Сайт «просто аккуратный» — это провал.

## Процесс (обязателен, шаги не пропускать)

1. **Бриф.** Уточни тему, аудиторию, одно главное действие на странице, тон (строгий / игривый / роскошный / дерзкий…).
   Попроси референсы (ссылки, скриншоты). Если их нет — предложи 2–3 конкретных направления с описанием и реальными сайтами-ориентирами (Awwwards, Godly, Siteinspire, Land-book).
2. **Концепция до кода.** Опиши коротко и жди одобрения:
   - эстетическое направление одной фразой (например, «швейцарская типографика + тёплая бумага + редакционная вёрстка»);
   - шрифты (2, максимум 3) и почему именно они;
   - палитра 3–5 цветов в hex, какой доминирует;
   - сетка и композиция: где асимметрия, где воздух, где плотность;
   - характер движения и 1–2 «сигнатурные» анимационные сцены;
   - одна запоминающаяся фишка, ради которой сайт запомнят.
3. **Вёрстка** по утверждённой концепции.
4. **Визуальная проверка через Playwright.** Скриншоты на 1440px и 390px, плюс несколько точек скролла.
   Критически оцени: ритм, выравнивания, переносы заголовков, контраст, «ИИшность». Исправь. Минимум 2 круга.
5. **Полировка:** микровзаимодействия, hover-состояния, фокус, `prefers-reduced-motion`, скорость загрузки.

## Запрещено (типичные признаки ИИ-дизайна)

- Фиолетово-синие / розово-фиолетовые градиенты, неоновое свечение, blur-пятна на фоне.
- Glassmorphism-карточки, одинаковые `rounded-2xl` + `shadow-lg` на всём.
- Шрифты по умолчанию: Inter, Roboto, Arial, system-ui, Poppins, Montserrat, Space Grotesk.
- Hero-шаблон: бейдж «✨ New» → центрированный заголовок → подзаголовок → две кнопки.
- Сетка «3 карточки с иконкой, заголовком и двумя строками текста».
- Эмодзи вместо иконок; случайные иконки Lucide «для красоты».
- Всё выровнено по центру; одинаковые отступы между всеми секциями.
- Анимация «fade-up каждого элемента при скролле» как единственный приём.
- Пустые маркетинговые фразы: «Unlock», «Elevate», «Seamless», «Boost your…», «Revolutionize».
- Lorem ipsum и фейковые логотипы «Trusted by».

## Как делать вместо этого

**Типографика — главный инструмент.**
- Крупный контраст размеров (заголовки 8–15vw допустимы), выразительный акцентный шрифт + спокойный текстовый.
- Источники: Google Fonts (менее заезженные), Fontshare, Velvetyne, Collletttivo. Serif, grotesk, mono — сочетай осознанно.
- Работай с межбуквенным, межстрочным, `text-wrap: balance`, висячей пунктуацией, переносами.

**Композиция.**
- Асимметрия, смелые обрезки, наложения, элементы, выходящие за сетку.
- Чередуй плотные и воздушные секции; меняй ритм.
- Редакционные приёмы: номера секций, подписи, колонтитулы, тонкие линейки, мелкий служебный текст.

**Цвет и фактура.**
- Одна доминанта + резкий акцент. Нейтральные тона — с температурой (тёплая бумага, холодный графит), не чистые #fff/#000.
- Фактура: зерно, бумага, фото с характером, дуотон, реальные материалы.

**Изображения.** Настоящие фото или сгенерированные в едином стиле. Без стоковой «улыбающейся команды за ноутбуком».

**Контент.** Реальные, конкретные тексты с голосом бренда, цифры, имена. Если текста нет — напиши правдоподобный под тему.

## Движение

- Стек: **GSAP + ScrollTrigger**, **Lenis** (плавный скролл), SplitText/split-type для текста. В React — **Motion**.
- Лучше 1–2 продуманные сцены (pinned-секция, горизонтальный скролл, раскрытие заголовка по буквам, маска на фото, параллакс), чем анимация на всём подряд.
- Кастомные easing (`expo.out`, `power4.inOut`), осмысленная хореография с задержками.
- Обязательно уважать `prefers-reduced-motion`.
- Перед использованием GSAP, ScrollTrigger, Lenis, Motion, Three.js и других библиотек сверяй актуальный API и способ установки через MCP **context7** (или **ref**), а не по памяти. Особенно это касается плагинов GSAP, импортов и breaking changes между версиями.
- Сначала опиши сцену словами (что движется, в каком порядке, какое ощущение), потом пиши код. После — проверь в Playwright по кадрам скролла.

## Технические правила

- По умолчанию: Vite + чистый HTML/CSS/JS (или Astro, если страниц несколько). React — только если нужен.
- Каждый лендинг в своей папке.
- CSS-переменные для токенов (цвета, шрифты, отступы); `clamp()` для адаптивной типографики.
- Мобильная версия — не «ужатый десктоп», а продуманная отдельно.
- Семантичная вёрстка, alt-тексты, видимый фокус, контраст AA.
- Шрифты: `font-display: swap`, preload ключевых; картинки — AVIF/WebP, lazy-load.

## Журнал вкуса

Сюда записываем, что понравилось и что нет после каждого лендинга. Эти пункты важнее общих правил выше.

- **Sirius Publishing House (2026-10)** — понравилось целиком: сквозной сюжет одного героя (перо) через все сцены; флэт-лэй (камера сверху, бумага = стол) с настоящими мягкими тенями; процедурные 3D-объекты вместо стоковых моделей; рукопись с раскрытием строго за кончиком пера; «окисление» чернил (свежие синие → сухие сепия) как фишка для своих; переходы сцен через поведение чернил (разлив ночи, стекание), а не fade; книжная вёрстка разворотов (канон полей, буквица, колонтитулы, фолио); бумажная карточка-листок поверх ночного неба.
- Не понравилось: вспышка страницы без стилей при загрузке. CSS подключать `<link>` в `<head>`, а не импортом из JS.
